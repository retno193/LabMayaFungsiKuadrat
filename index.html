01 Bentuk Umum & Titik Potong Sumbu-X

Fungsi Kuadrat adalah fungsi polinomial berderajat dua dengan bentuk umum:

f(x) = ax² + bx + c  atau  y = ax² + bx + c  (a ≠ 0)
  • Kurva representasi grafis fungsi kuadrat pada bidang Kartesius dinamakan parabola.
  • Akar-akar fungsi kuadrat (x₁ dan x₂) merupakan pembuat nol fungsi, yaitu nilai x ketika f(x) = 0.
  • Secara geometris, akar-akar tersebut adalah absis titik potong grafik terhadap sumbu-x, yakni pada koordinat (x₁, 0) dan (x₂, 0).

02 Menyusun Persamaan dari Perkalian Faktor

Jika akar-akar x₁ dan x₂ diketahui, persamaan kuadrat dapat dibentuk melalui perkalian faktor linear:

a · (x − x₁)(x − x₂) = 0

Dengan mengalikan setiap suku secara aljabar distributif (perkalian pelangi):

(x − x₁)(x − x₂) = x² − x₂·x − x₁·x + x₁·x₂
(x − x₁)(x − x₂) = x² − (x₁ + x₂)x + x₁·x₂ = 0

Contoh: Jika x₁ = 2 dan x₂ = -5, maka (x − 2)(x + 5) = x² + 3x − 10 = 0.

03 Teorema Vieta: Jumlah & Hasil Kali Akar

Matematikawan François Viète merumuskan relasi matematis langsung antara akar-akar dengan koefisien persamaan ax² + bx + c = 0:

Jumlah Akar (S)
x₁ + x₂ = −b/a
Hasil Kali Akar (P)
x₁ · x₂ = c/a

Untuk koefisien a = 1, persamaan kuadrat baru dapat langsung ditulis:

04 Pengaruh Koefisien a Terhadap Grafik

Koefisien kuadratik a (a ≠ 0) menentukan arah keterbukaan dan derajat kelengkungan parabola:

Jika a > 0 (Positif): Parabola terbuka ke ATAS (∪) dan memiliki titik balik minimum.
Jika a < 0 (Negatif): Parabola terbuka ke BAWAH (∩) dan memiliki titik balik maksimum.
  • Semakin besar nilai mutlak |a|, kurva parabola semakin ramping / curam.
  • Semakin kecil nilai mutlak |a|, kurva parabola semakin melebar / landai.
  • Mengubah nilai a tidak menggeser titik potong sumbu-x (x₁ dan x₂ tetap sama).

05 Karakteristik Tanda Akar & Posisi Grafik

Tanda dan relasi dari kedua akar menghasilkan karakteristik posisi unik pada kurva parabola:

1. Akar Berbeda Tanda (x₁ > 0, x₂ < 0): Titik potong berada di kiri dan kanan sumbu-y (sumbu-y terletak di antara kedua akar).
2. Akar Bertanda Sama: Kedua titik potong berada di satu sisi sumbu-y (keduanya di sumbu-x positif atau sumbu-x negatif).
3. Akar Kembar (x₁ = x₂): Diskriminan D = 0. Parabola menyinggung sumbu-x di tepat satu titik (titik puncak menempel di sumbu-x).

Glosarium Istilah Kunci Fungsi Kuadrat
Fungsi Kuadrat
Fungsi polinomial berderajat dua dengan bentuk umum f(x) = ax² + bx + c (a ≠ 0), di mana representasi grafisnya pada bidang Kartesius membentuk kurva lengkung simetris yang disebut parabola.
Akar Persamaan (Roots)
Nilai-nilai variabel x pembuat nol fungsi (f(x) = 0). Secara geometris, akar-akar ini merupakan absis titik potong kurva parabola dengan sumbu-x pada koordinat (x₁, 0) dan (x₂, 0).
Parabola
Kurva bidang dua dimensi yang berbentuk lengkungan simetris mulus menyerupai cermin, dihasilkan dari himpunan semua titik (x, y) yang memenuhi persamaan kuadrat y = ax² + bx + c.
Koefisien Kuadratik (a)
Faktor pengali suku kuadrat x² yang mengontrol kelengkungan kurva. Nilai a menentukan arah bukaan (a > 0 membuka ke atas, a < 0 membuka ke bawah) serta derajat kelangsingan atau kelebaran parabola.
Diskriminan (D)
Nilai penentu jenis akar yang dihitung melalui rumus D = b² − 4ac. Nilai D mengidentifikasi apakah parabola memotong sumbu-x di dua titik (D > 0), menyinggung (D = 0), atau tidak memotong (D < 0).
Titik Puncak (Vertex)
Titik balik ekstrem pada parabola, berupa nilai minimum jika kurva terbuka ke atas (a > 0) atau nilai maksimum jika kurva terbuka ke bawah (a < 0), dengan koordinat puncak (−b/2a, −D/4a).
Sumbu Simetri
Garis khayal vertikal tegak lurus sumbu-x dengan persamaan x = −b/2a yang membagi kurva parabola menjadi dua sisi yang simetris dan kongruen secara sempurna.
Teorema Vieta
Relasi aljabar yang menghubungkan akar-akar dengan koefisien persamaan kuadrat, yaitu jumlah akar x₁ + x₂ = −b/a dan hasil kali akar x₁·x₂ = c/a, menjadi dasar menyusun persamaan baru.
Faktorisasi Linear
Metode menyusun persamaan kuadrat dengan mengalikan dua faktor linear suku aljabar a(x − x₁)(x − x₂) = 0 berdasarkan pasangan akar x₁ dan x₂ yang telah diselidiki.
Konstanta (c)
Suku tetap tanpa variabel pada bentuk kuadrat. Nilai konstanta c secara tepat menunjukkan koordinat titik potong kurva parabola terhadap sumbu-y pada titik (0, c).
